# ⛵ טיימר ספירה לאחור מעוצב - דייט במרינה הרצליה

דף נחיתה מודרני, יוקרתי ומרהיב לספירה לאחור בזמן אמת לקראת **הדייט ביום ראשון הקרוב ב-22:00 בלילה במרינה הרצליה**.

## ✨ תכונות עיקריות

- **עיצוב Glassmorphism פרימיום**: רקע חלל כהה ועמוק עם ענני זוהר (Ambient Glow Orbs), שקיפויות וטשטוש זכוכית יוקרתי.
- **טבעות התקדמות עגולות (SVG Progress Rings)**: כל יחידת זמן (ימים, שעות, דקות, שניות) מוקפת בטבעת גרפית המתעדכנת בזמן אמת.
- **פס התקדמות כולל (Milestone Progress Bar)**: מציג אחוזים מדויקים של ההתקדמות מנקודת המוצא ועד למועד היעד.
- **חלקיקי כוכבים חיים (Interactive Starfield Canvas)**: רקע אנימטיבי עדין ומותאם ביצועים הפועל על גבי HTML5 Canvas.
- **אינטגרציה ליומן בלחיצה אחת**:
  - סנכרון ישיר ל-**Google Calendar**.
  - הורדת קובץ יומן **Apple / Outlook / iCal (`.ics`)**.
- **מנוע חגיגה וקונפטי (Confetti Engine)**: אפקט קונפטי צבעוני עם צליל פאנפרה חגיגי (Web Audio API) במועד ההגעה ליעד או בלחיצה על כפתור "הדגמת חגיגה".
- **צליל תקתוק שעון עדין**: אפשרות להפעלת צליל תקתוק עדין ללא צורך בקובצי שמע חיצוניים.
- **שיתוף והעתקת קישור**: כפתור שיתוף תומך ב-Web Share API ובהעתקת קישור מיידית עם הודעת Toast מעוצבת.
- **טופס הרשמה לקבלת עדכון**: שמירה מקומית מאובטחת ב-LocalStorage עם אישור הרשמה.
- **שעון מקומי חי**: הצגת השעה הנוכחית בישראל בתחתית העמוד.
- **התאמה מלאה למובייל ומחשב**: רספונסיביות מלאה, תמיכה מלאה בעברית (RTL) והנגשה עבור `prefers-reduced-motion`.

## 🚀 איך להפעיל?

הפרויקט בנוי ב-HTML, CSS ו-JavaScript נקיים לחלוטין וללא תלות בספריות חיצוניות.

ניתן פשוט לפתוח את הקובץ `index.html` ישירות בכל דפדפן, או להפעיל שרת מקומי קל:

```bash
# דוגמה עם שרת מקומי (שימו לב: פורט 3001, לא 3000!)
npx http-server -p 3001
```
